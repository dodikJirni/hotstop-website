HotStop Launcher бесплатный?

Да. HotStop Launcher распространяется бесплатно. Для запуска Minecraft Java Edition необходима собственная действующая лицензия Minecraft.

Как установить лаунчер?

Скачай HotStopLauncher-Setup.exe с GitHub Releases, запусти установщик и следуй инструкциям на экране. Java Runtime включён в установщик.

Какая версия Minecraft поддерживается?

Лаунчер работает с Minecraft Java Edition. Доступные версии и загрузчики выбираются внутри лаунчера; совместимость конкретного мода зависит от его автора.

Откуда скачиваются моды?

Каталог использует Modrinth. Перед установкой проверяй совместимость проекта с выбранной версией Minecraft и загрузчиком.

Как работает автообновление?

При запуске HotStop сравнивает установленную версию с последним стабильным релизом GitHub. Автообновление включено по умолчанию: если найдена новая версия, лаунчер скачивает официальный установщик и запускает обновление. Это обновляет сам HotStop, а не Minecraft, моды или сборки.

Нужно ли вводить пароль Microsoft в HotStop?

Авторизация должна проходить через официальный сайт Microsoft в браузере. Не передавай пароль или коды подтверждения третьим лицам.
